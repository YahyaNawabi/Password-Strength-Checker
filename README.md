# 🔐 Password Strength Checker

A sleek and simple Password Strength Checker web app built using HTML, CSS, and JavaScript. This tool evaluates the strength of a password as the user types and provides real-time feedback indicating whether it's **Weak**, **Medium**, or **Strong**. It also includes a toggle to show or hide the password for better usability.

---

## 🚀 Features

- ✅ Real-time password strength evaluation
- 👀 Toggle button to show/hide the password
- 🌈 Dynamic styling based on password strength (color and background change)
- 💡 User-friendly and modern interface
- ⚙️ No external libraries — built with pure HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
